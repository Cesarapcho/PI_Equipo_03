# Módulo Electrónico – Visualización 3D de PCB

Este módulo forma parte del **Proyecto Integrador – Equipo 03** y presenta el diseño de la placa de circuito impreso (PCB) utilizada para integrar los componentes electrónicos del sistema.

## Visualizador 3D interactivo

Se ha implementado un visualizador web que permite explorar el diseño de la PCB de manera interactiva, sin necesidad de instalar software CAD.

**Funcionalidades:**
- Rotación del modelo en 360°.
- Acercamiento y alejamiento (zoom).
- Visualización desde diferentes perspectivas.
- Exploración de la estructura tridimensional.

### [Abrir visualizador 3D de la PCB](https://cesarapcho.github.io/PCB-GitHub-Pages/)

**Tecnologías:** HTML, JavaScript, WebGL y modelo 3D.
