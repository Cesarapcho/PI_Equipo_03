# 🏗️🚀 Proyecto de Equipo

<div align="center">

## Sistema de Apuntalamiento Inteligente

### Sistema de tres puntales mecánicos coordinados para estabilización temporal

🏗️ **3 puntales** &nbsp;•&nbsp;
📊 **Medición de carga** &nbsp;•&nbsp;
📐 **Monitoreo** &nbsp;•&nbsp;
⚙️ **Ajuste automático** &nbsp;•&nbsp;
🧠 **Control coordinado** &nbsp;•&nbsp;
🔒 **Seguridad mecánica**

</div>

<br>

El proyecto propone desarrollar un **sistema experimental de apuntalamiento inteligente compuesto por tres puntales mecánicos instrumentados y coordinados electrónicamente**.

Los puntales tendrán aproximadamente **1 metro de longitud** y serán utilizados exclusivamente en un **banco de pruebas de laboratorio**, donde será posible aplicar cargas controladas y estudiar el comportamiento del sistema.

El objetivo principal es determinar en tiempo real la carga soportada por cada puntal y actuar sobre ellos cuando se detecte una distribución inadecuada.

El principio general del sistema es:

> **MEDIR → COMPARAR → DECIDIR → AJUSTAR → VERIFICAR**

---

# ❗ Problema identificado

Después de un sismo, derrumbe parcial u otro evento que produzca daño estructural, pueden emplearse sistemas de apuntalamiento temporal para sostener determinados elementos mientras se realizan evaluaciones o intervenciones.

Un problema importante aparece cuando existen **varios puntales soportando una misma estructura**.

Aunque externamente los puntales puedan parecer correctamente instalados, la carga aplicada sobre ellos no necesariamente se distribuye de manera uniforme.

Por ejemplo:

```text
             ESTRUCTURA

     ━━━━━━━━━━━━━━━━━━━━━━━

          ↓      ↓      ↓

       ┌────┐ ┌────┐ ┌────┐
       │ P1 │ │ P2 │ │ P3 │
       └────┘ └────┘ └────┘

        F1     F2     F3
````

Podría ocurrir una situación como:

```text
F1 = 150 N
F2 = 410 N
F3 = 140 N
```

A pesar de utilizar tres puntales, el **puntal P2 estaría soportando una proporción considerablemente mayor de la carga**.

Esto puede producirse por:

* Diferencias pequeñas en la longitud de los puntales.
* Irregularidades en las superficies de contacto.
* Deformaciones de la estructura.
* Asentamiento progresivo.
* Desplazamientos.
* Errores durante la instalación.
* Variaciones posteriores a la colocación del apuntalamiento.

Los sistemas convencionales dependen principalmente de la correcta instalación inicial y de inspecciones posteriores.

La pregunta que motiva el proyecto es:

> **¿Cómo podemos conocer continuamente la carga que soporta cada puntal y corregir automáticamente una distribución inadecuada?**

---

# 💡 Innovación propuesta

La innovación del proyecto consiste en transformar un sistema de apuntalamiento principalmente **pasivo** en un sistema **instrumentado y coordinado**.

Cada uno de los tres puntales será capaz de:

* Medir la carga axial que soporta.
* Determinar su posición o desplazamiento.
* Detectar inclinaciones no deseadas.
* Enviar información al sistema de control.
* Modificar controladamente su longitud efectiva.
* Detener el movimiento al alcanzar límites establecidos.

El **ESP32** procesará conjuntamente la información de los tres módulos.

De esta forma, el sistema no analizará cada puntal de manera aislada, sino como parte de un conjunto:

```text
PUNTAL 1 ──┐
           │
PUNTAL 2 ──┼──► ESP32 ──► ALGORITMO DE CONTROL
           │                    │
PUNTAL 3 ──┘                    ▼
                         AJUSTE DE PUNTALES
```

El sistema podrá detectar situaciones como:

```text
F2 >> F1
F2 >> F3
```

y realizar pequeños ajustes controlados para intentar reducir la diferencia entre las cargas.

# 🛠️ Características del Proyecto

## 🏗️ Tres puntales mecánicos

El prototipo empleará:

> **3 puntales mecánicos de aproximadamente 1 metro de longitud.**

Los puntales no serán hidráulicos ni neumáticos.

El mecanismo deberá permitir realizar pequeñas modificaciones controladas de longitud mediante un sistema electromecánico.

---

## 📊 Medición de carga

Cada puntal tendrá un sistema independiente de medición de fuerza.

Una alternativa de implementación consiste en utilizar:

* **Celda de carga.**
* **Módulo de adquisición HX711 o equivalente.**
* Conversión de la señal a unidades de fuerza.

Se tendrán tres variables principales:

```text
F1 = carga del puntal 1
F2 = carga del puntal 2
F3 = carga del puntal 3
```

---

## 📐 Medición de posición

Será necesario conocer cuánto se modifica la posición de cada sistema de ajuste.

Dependiendo del mecanismo final podrán emplearse:

* Encoder rotativo.
* Sensor de desplazamiento lineal.
* Potenciómetro lineal.
* Encoder integrado en el motor.

Esto permitirá conocer variables como:

```text
x1 = posición del puntal 1
x2 = posición del puntal 2
x3 = posición del puntal 3
```

---

## 📏 Medición de inclinación

Como medida adicional de supervisión, cada módulo podrá incorporar una **IMU o inclinómetro**.

Su función será detectar condiciones donde un puntal deje de trabajar aproximadamente de forma axial.

Ejemplo:

```text
θ1 = inclinación de P1
θ2 = inclinación de P2
θ3 = inclinación de P3
```

---

## ⚙️ Ajuste electromecánico

El ajuste de cada puntal será realizado mediante un sistema motorizado acoplado al mecanismo mecánico de regulación.

La solución final deberá seleccionarse considerando:

* Fuerza requerida.
* Torque.
* Velocidad.
* Precisión.
* Capacidad de bloqueo.
* Facilidad de integración.
* Disponibilidad de componentes en Lima.
* Seguridad.

El accionamiento podrá incorporar:

* Motorreductor DC con encoder.

o

* Motor paso a paso con transmisión adecuada.

La selección definitiva dependerá de los cálculos mecánicos.

---

## 🧠 Control mediante ESP32

El controlador principal será un:

> **ESP32**

Sus funciones incluirán:

* Leer los sensores.
* Procesar las fuerzas medidas.
* Comparar las cargas de los tres puntales.
* Detectar desequilibrios.
* Ejecutar la lógica de control.
* Accionar los motores.
* Supervisar los límites de funcionamiento.
* Gestionar alarmas.
* Registrar datos experimentales.

---

## 🔒 Bloqueo mecánico

El sistema deberá evitar depender exclusivamente del motor para mantener una posición.

Por este motivo se evaluará un mecanismo con:

* Tornillo mecánico autoblocante.

o

* Sistema de bloqueo independiente.

El objetivo es reducir la posibilidad de movimiento accidental cuando el actuador se encuentre detenido.

---

## 🚨 Detección de condiciones anómalas

El sistema deberá poder detectar, como mínimo:

* Sobrecarga.
* Carga excesivamente desigual.
* Sensor fuera de rango.
* Pérdida de señal.
* Inclinación excesiva.
* Movimiento fuera del recorrido permitido.
* Error del actuador.
* Pérdida de alimentación.
* Activación de parada de emergencia.

# ⚙️ Funcionamiento General

El sistema funcionará mediante un ciclo continuo de supervisión.

## 1. Inicialización

El ESP32 verifica:

* Comunicación con sensores.
* Estado de las celdas de carga.
* Posición de los actuadores.
* Estado de finales de carrera.
* Estado de emergencia.

---

## 2. Medición

Se obtienen:

```text
F1
F2
F3
```

y, cuando corresponda:

```text
x1, x2, x3
θ1, θ2, θ3
```

---

## 3. Cálculo de carga total

El sistema calcula:

```text
W = F1 + F2 + F3
```

donde:

* `W` = carga vertical total registrada.
* `F1` = fuerza medida en P1.
* `F2` = fuerza medida en P2.
* `F3` = fuerza medida en P3.

---

## 4. Evaluación de distribución

Como primera referencia puede calcularse una carga media:

```text
Fmedia = (F1 + F2 + F3) / 3
```

Posteriormente deberán considerarse también la geometría del sistema y las ecuaciones de equilibrio.

Se calcula el error de cada puntal:

```text
e1 = F1 - Fobjetivo1
e2 = F2 - Fobjetivo2
e3 = F3 - Fobjetivo3
```

---

## 5. Decisión

Si las cargas se encuentran dentro de los límites establecidos:

```text
        CARGAS ADECUADAS
              │
              ▼
       ESTADO ESTABLE
```

Si se detecta un desequilibrio:

```text
     DESEQUILIBRIO DETECTADO
              │
              ▼
       CALCULAR CORRECCIÓN
              │
              ▼
      REALIZAR AJUSTE PEQUEÑO
              │
              ▼
          VOLVER A MEDIR
```

---

## 6. Actuación

Los motores realizan movimientos pequeños y controlados.

El sistema deberá evitar grandes desplazamientos en una sola operación.

El principio será:

> **Mover poco → medir nuevamente → evaluar → decidir**

---

## 7. Verificación

Después de cada movimiento se vuelven a obtener las cargas.

```text
MEDICIÓN
   │
   ▼
ANÁLISIS
   │
   ▼
¿EQUILIBRADO?
   │
 ┌─┴─┐
 │   │
SÍ   NO
 │   │
 ▼   ▼
FIN  AJUSTAR
      │
      └──────► MEDIR
```

---

# 📐 Fundamento de Control

El sistema no buscará simplemente que:

```text
F1 = F2 = F3
```

en cualquier situación.

La distribución correcta dependerá también de:

* Posición de la carga.
* Distancia entre puntales.
* Geometría de la estructura.
* Rigidez del banco de pruebas.
* Condiciones de apoyo.

Por ello, el algoritmo deberá respetar las ecuaciones de equilibrio estático.

Para una condición simplificada:

```text
ΣFy = 0
```

por lo que:

```text
F1 + F2 + F3 = W
```

También deberá cumplirse:

```text
ΣM = 0
```

respecto al punto de referencia seleccionado.

Esto permitirá calcular la distribución teórica de fuerzas que debería soportar cada puntal.

El controlador podrá comparar:

```text
FUERZA TEÓRICA
      vs
FUERZA MEDIDA
```

y utilizar el error resultante para determinar la corrección necesaria.

# 🧮 Cálculos de Ingeniería

Antes de definir las cargas máximas del prototipo deberán realizarse cálculos que permitan justificar cada elemento.

Entre los principales cálculos se encuentran:

## 1. Equilibrio estático

Se determinarán las reacciones correspondientes a los tres puntales:

```text
ΣFx = 0
ΣFy = 0
ΣM  = 0
```

---

## 2. Esfuerzo axial

Para cada puntal:

```text
σ = F / A
```

donde:

* `σ` = esfuerzo normal.
* `F` = fuerza axial.
* `A` = área transversal resistente.

---

## 3. Pandeo

Debido a que los puntales trabajan principalmente a compresión, deberá verificarse la estabilidad frente a pandeo.

Como referencia teórica podrá estudiarse la carga crítica de Euler:

```text
Pcr = π²EI / (KL)²
```

donde:

* `E` = módulo de elasticidad.
* `I` = segundo momento de área.
* `K` = factor asociado a las condiciones de apoyo.
* `L` = longitud efectiva.

Para el diseño definitivo deberán utilizarse los modelos y normas que correspondan al tipo real de puntal empleado.

---

## 4. Factor de seguridad

La carga experimental máxima deberá mantenerse por debajo de la capacidad admisible del elemento más restrictivo del sistema.

```text
FS = Capacidad / Carga_de_trabajo
```

Se deberán considerar:

* Puntal.
* Celda de carga.
* Estructura de ensayo.
* Uniones.
* Tornillos.
* Actuadores.
* Elementos de transmisión.

---

## 5. Torque de accionamiento

Si se utiliza un mecanismo de tornillo, deberá calcularse el torque necesario para modificar la longitud del puntal bajo carga.

La selección del motor deberá realizarse a partir de:

```text
Carga requerida
      ↓
Fuerza axial
      ↓
Mecanismo de tornillo
      ↓
Torque requerido
      ↓
Factor de seguridad
      ↓
Selección del motor
```

---

## 6. Resolución de medición

También deberá determinarse:

* Capacidad máxima de la celda.
* Sensibilidad.
* Resolución.
* Error.
* Repetibilidad.
* Incertidumbre experimental.

Esto permitirá justificar si el sistema puede detectar diferencias de carga suficientemente pequeñas.

# 🛡️ Seguridad del Sistema

Debido a que el concepto del proyecto está relacionado con sistemas que potencialmente podrían utilizarse en aplicaciones estructurales, la seguridad tendrá un papel central.

El prototipo deberá incorporar diferentes niveles de protección.

### Nivel mecánico

* Puntales mecánicos.
* Bloqueo o mecanismo autoblocante.
* Topes físicos.
* Uniones dimensionadas mediante cálculo.

### Nivel eléctrico

* Protección de alimentación.
* Cableado correctamente dimensionado.
* Protección de motores y controladores.

### Nivel electrónico

* Finales de carrera.
* Supervisión de sensores.
* Detección de valores fuera de rango.

### Nivel de software

* Límites máximos de carga.
* Límites de desplazamiento.
* Verificación de sensores antes de mover los actuadores.
* Parada ante pérdida de información crítica.

### Nivel humano

Se incorporará una:

> 🚨 **Parada de emergencia**

capaz de detener inmediatamente el movimiento de los actuadores durante las pruebas.

# ⚠️ Alcance del Prototipo

> **Este proyecto corresponde a un prototipo académico y experimental de laboratorio.**

El sistema será utilizado para estudiar:

* Distribución de cargas.
* Instrumentación.
* Automatización.
* Control coordinado.
* Seguridad funcional.
* Comportamiento mecánico.

No será diseñado inicialmente para sostener una edificación real ni para ser utilizado directamente en operaciones de rescate.

Antes de considerar una aplicación real sería necesario realizar, entre otros:

* Diseño estructural completo.
* Ensayos certificados.
* Validación de materiales.
* Análisis de modos de falla.
* Verificación normativa.
* Ensayos de carga.
* Factores de seguridad adecuados.
* Evaluación por profesionales especializados.
* Certificación del sistema.

---

# 🌎 Impacto Esperado

El proyecto busca demostrar que es posible integrar tecnologías de bajo costo con elementos mecánicos de apuntalamiento para obtener información que normalmente no está disponible de manera continua.

Entre sus posibles beneficios se encuentran:

* Conocer la carga real soportada por cada puntal.
* Detectar redistribuciones de carga.
* Identificar puntales sobrecargados.
* Registrar información durante las pruebas.
* Reducir la dependencia exclusiva de inspecciones visuales.
* Investigar estrategias automáticas de corrección.
* Desarrollar herramientas de apoyo para sistemas de estabilización temporal.

El objetivo final del proyecto académico será demostrar experimentalmente el concepto de:

> **Apuntalamiento + Sensores + Control + Actuación coordinada**
