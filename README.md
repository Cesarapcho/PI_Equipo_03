# 🌍 Sobre el Equipo

Somos el **Equipo 03** del curso **Proyecto Integrador 2026-2** de la **Universidad Peruana Cayetano Heredia**, conformado por estudiantes de las carreras de **Ingeniería Industrial e Informática**.

Nuestro propósito es integrar conocimientos de ingeniería, diseño, programación y sistemas de control para desarrollar una solución tecnológica orientada a una problemática real relacionada con la **estabilidad y seguridad temporal de estructuras dañadas**.

El proyecto se desarrolla aplicando una metodología de diseño centrada en:

> 💡 **Investigar, diseñar, prototipar, evaluar e iterar soluciones con impacto social, tecnológico y estructural.**

Nuestro trabajo se encuentra principalmente relacionado con el:

### 🏙️ ODS 11 — Ciudades y Comunidades Sostenibles

### 🎯 Meta 11.5 — Reducción del impacto de los desastres

Buscamos contribuir al desarrollo de soluciones tecnológicas orientadas a la **estabilización temporal de estructuras dañadas**, apoyando procesos de evaluación, reparación y recuperación posteriores a situaciones de emergencia.

# 🏗️🚀 Proyecto de Equipo

<div align="center">

## Sistema modular de apuntalamiento inteligente
### Para estabilización temporal de estructuras dañadas

🏗️ **Apuntalamiento** &nbsp;•&nbsp;
📊 **Medición de carga** &nbsp;•&nbsp;
📐 **Monitoreo** &nbsp;•&nbsp;
⚙️ **Actuación** &nbsp;•&nbsp;
🔒 **Bloqueo mecánico**

</div>

<br>

Nuestro proyecto propone el desarrollo de un **sistema modular de apuntalamiento inteligente para la estabilización temporal de estructuras dañadas**, incorporando medición de carga, monitoreo de desplazamiento, ajuste controlado y bloqueo mecánico.

El sistema busca mantener condiciones controladas de soporte mientras se producen variaciones en las condiciones de la estructura.

Cada módulo integra funciones orientadas a:

- 📊 **Medición de carga**
- 📐 **Monitoreo de desplazamiento**
- ⚙️ **Ajuste controlado**
- 🔒 **Bloqueo mecánico**
- 🚨 **Detección de condiciones anómalas**
- 🧠 **Coordinación entre módulos**

A diferencia de un sistema convencional de apuntalamiento que depende principalmente de una configuración estática y supervisión manual, la propuesta busca incorporar un ciclo de:

> **MEDIR → ANALIZAR → ACTUAR → VERIFICAR**

# 🎯 Relación con el ODS 11

### 🏙️ ODS 11 — Ciudades y Comunidades Sostenibles

### 🎯 Meta 11.5 — Reducción del impacto de los desastres

La Meta 11.5 busca reducir significativamente el número de personas afectadas y las pérdidas económicas directas ocasionadas por desastres.

La propuesta se relaciona con esta meta debido a que busca desarrollar una tecnología orientada a la **estabilización temporal de infraestructura dañada**, como parte de procesos de respuesta, evaluación, reparación y recuperación.

El proyecto se vincula particularmente con el componente de la Meta 11.5 relacionado con:

> **Daños a infraestructura crítica y afectaciones ocasionadas por desastres.**

La contribución del proyecto será evaluada mediante la validación experimental del sistema y su capacidad para mantener condiciones de soporte controladas.

---

# 🛠️ Características del Proyecto

### 📊 Medición de carga

Cada módulo deberá determinar la carga axial que soporta durante la operación.

### 📐 Monitoreo de desplazamiento

El sistema permitirá identificar cambios en la posición o desplazamiento de los módulos.

### ⚙️ Ajuste controlado

El sistema permitirá modificar controladamente la longitud efectiva del módulo de soporte dentro de los límites establecidos.

### 🔒 Bloqueo mecánico

Cada módulo contará con un mecanismo destinado a mantener la posición alcanzada independientemente del accionamiento.

### 🧠 Control coordinado

El controlador analizará la información proveniente de los diferentes módulos para determinar las condiciones de operación.

### 🚨 Detección de fallos

El sistema deberá identificar condiciones como:

- Sobrecarga.
- Medición inválida.
- Pérdida de comunicación.
- Pérdida de alimentación.
- Desplazamiento fuera de rango.
- Fallo del sistema de actuación.
