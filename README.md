# 🏗️ El Proyecto

<div align="center">

## Sistema Modular de Apuntalamiento Inteligente

### Para estabilización temporal de estructuras dañadas

<br>

<img src="https://img.shields.io/badge/P1-Puntal%201-FD9D24?style=for-the-badge"/>
<img src="https://img.shields.io/badge/P2-Puntal%202-D47B00?style=for-the-badge"/>
<img src="https://img.shields.io/badge/P3-Puntal%203-B85F00?style=for-the-badge"/>

</div>

<br>

Nuestra propuesta consiste en un sistema formado por **tres puntales capaces de trabajar de manera coordinada**.

Cada uno podrá conocer la carga que soporta y transmitir esa información a un controlador.

La idea es que el sistema pueda **identificar diferencias importantes entre los tres apoyos** y responder mediante ajustes controlados.

<div align="center">

### 📊 Sensar &nbsp;→&nbsp; 🧠 Analizar &nbsp;→&nbsp; ⚙️ Ajustar &nbsp;→&nbsp; ✅ Verificar

</div>

---

# ⚠️ El Problema

Los puntales son utilizados como elementos de soporte temporal durante trabajos de reparación, construcción o estabilización.

Sin embargo, instalar varios puntales no garantiza automáticamente que todos estén soportando la estructura de la misma manera.

Una variación en la estructura puede provocar que:

```mermaid
flowchart TB
    E["🏗️ ESTRUCTURA"]:::structure

    P1["P1<br/><b>30 kg</b>"]:::support
    P2["P2<br/><b>75 kg</b><br/>⚠️ Mayor carga"]:::alert
    P3["P3<br/><b>25 kg</b>"]:::support

    E --> P1
    E --> P2
    E --> P3

    classDef structure fill:#5B3200,color:#FFFFFF,stroke:#FD9D24,stroke-width:3px;
    classDef support fill:#2B1700,color:#FFFFFF,stroke:#FD9D24,stroke-width:2px;
    classDef alert fill:#FD9D24,color:#2B1700,stroke:#C96F00,stroke-width:4px;

    linkStyle default stroke:#FD9D24,stroke-width:2px;
```

<div align="center">

### ⚠️ Los tres puntales están presentes...

### pero uno podría estar soportando una carga considerablemente mayor.

</div>

La dificultad es que este comportamiento **no siempre puede determinarse visualmente**.

---

# 💡 Nuestra Propuesta

En lugar de utilizar tres puntales completamente independientes, proponemos convertirlos en un **sistema coordinado**.

Cada módulo incorpora conceptualmente:

<p align="center">
  <img src="https://img.shields.io/badge/01-MEDICI%C3%93N%20DE%20CARGA-FD9D24?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/02-MONITOREO-D47B00?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/03-ACTUACI%C3%93N-B85F00?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/04-BLOQUEO-8C4600?style=for-the-badge"/>
</p>

El controlador recibe información proveniente de los tres puntales:

```mermaid
flowchart LR
    P1["P1<br/>📊 Sensor"]:::module
    P2["P2<br/>📊 Sensor"]:::module
    P3["P3<br/>📊 Sensor"]:::module
    C["🧠 CONTROLADOR<br/><br/>Análisis · Coordinación"]:::controller

    P1 --> C
    P2 --> C
    P3 --> C

    classDef module fill:#2B1700,color:#FFFFFF,stroke:#FD9D24,stroke-width:2px;
    classDef controller fill:#FD9D24,color:#2B1700,stroke:#C96F00,stroke-width:3px;

    linkStyle default stroke:#FD9D24,stroke-width:2px;
```

y utiliza estas mediciones para conocer el estado general del sistema.

# ✨ ¿Dónde está la innovación?

### Apuntalamiento convencional

```mermaid
flowchart LR
    A["Instalar"] --> B["Ajustar"] --> C["Bloquear"] --> D["Inspeccionar"]

    classDef conventional fill:#2B1700,color:#FFFFFF,stroke:#8C4600,stroke-width:2px;
    class A,B,C,D conventional;
    linkStyle default stroke:#8C4600,stroke-width:2px;
```

### Nuestra propuesta

```mermaid
flowchart LR
    M["📊 Medir"] --> A["🧠 Analizar"] --> D["Decidir"] --> AJ["⚙️ Ajustar"] --> V["✅ Verificar"]
    V -. retroalimentación .-> M

    classDef smart fill:#FD9D24,color:#2B1700,stroke:#C96F00,stroke-width:2px;
    class M,A,D,AJ,V smart;
    linkStyle default stroke:#FD9D24,stroke-width:2px;
```

<br>

La innovación no se encuentra únicamente en el puntal.

Se encuentra en **hacer que tres elementos de soporte trabajen como un sistema**.

Nuestra propuesta integra:

- 📊 Información de carga.
- 🧠 Procesamiento de datos.
- ⚙️ Ajuste controlado.
- 🔒 Seguridad mecánica.
- 🔗 Coordinación entre los tres puntales.

<div align="center">

> **Pasamos de elementos pasivos e independientes a módulos instrumentados capaces de compartir información.**

</div>
