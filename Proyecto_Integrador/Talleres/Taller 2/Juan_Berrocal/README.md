# Taller 2 – Diseño de PCB

## Descripción

En este taller se realizó el diseño y desarrollo de una **placa de circuito impreso (PCB)**, incluyendo la elaboración del **esquemático**, el diseño de la **PCB en 2D** y la visualización del modelo **3D**.
