# Bocetos del sistema

Se desarrollaron tres propuestas de diseño para el sistema de evaluación vibroacústica de granadilla.

## Boceto 1

Propuesta de estructura cerrada que integra el gripper, la celda de carga, el servomotor y los componentes electrónicos en una distribución compacta.

</p>

**Esta alternativa fue seleccionada para continuar con el desarrollo del prototipo.**

## Boceto 2

Propuesta de estructura abierta con el gripper y la granadilla visibles, mientras que los componentes electrónicos se ubican en la base del sistema.

<p align="center">
  <img src="./imagenes/boceto_2.png" width="800">
</p>

## Boceto 3

Propuesta de estructura vertical abierta, con el gripper ubicado sobre la granadilla y los componentes electrónicos distribuidos en la base inferior.

<p align="center">
  <img src="./imagenes/boceto_3.png" width="800">
</p>

## Solución seleccionada

Se seleccionó el **Boceto 1** por presentar una mejor integración de los componentes, una estructura compacta y una configuración adecuada para el aislamiento vibroacústico.
